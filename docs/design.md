# 画面のデザイン

見た目は `src/styles/app.css` の 1ファイルです。UI ライブラリは使っていません。

## 考え方

題材は会社員が毎月受け取る給与明細です。机（背景）の上に紙の明細が 1枚載っている、という絵だけを強く見せ、ほかは控えめにしています。

- 入力と同時に計算する。ボタンは押させない
- 一番大きく見せるのは手取り。次に、額面が手取り・税金・社会保険に分かれる帯。その下に実物の明細と同じ「支給」「控除」の表と、「差引支給額 ＝ 総支給額 − 控除合計」の行
- 会社の負担は別の紙にして、「額面 ＋ 会社の負担 ＝ 会社が払う総額」を式で見せる
- 計算の前提と途中の数字は折りたたんでおき、確かめたい人だけが開く

## 色

| 名前 | 値 | 使う場所 |
| --- | --- | --- |
| 机 | `#e6ecf1` | 背景 |
| 紙 | `#ffffff` | 明細 |
| 墨 | `#17202b` | 文字、強い罫線 |
| 罫線 | `#b9c5cf` / `#dfe6ec` | 表 |
| 藍 | `#1f3f73` | 手取り、選択中の部品 |
| 朱 | `#c2412d` | 税金、手取り率の丸印、エラー |
| 黄土 | `#a87818` | 社会保険 |
| 青竹 | `#2f6f62` | 会社の負担 |

手取り・税金・社会保険の 3色は、帯・凡例・控除の行の印で同じ意味に使います。

## 文字

- BIZ UDPゴシック。日本語は端末の標準に任せ（Windows は同書体、Mac はヒラギノ）、英数字だけ同梱して金額の見た目をそろえる
- 金額は `tabular-nums` で桁を縦にそろえる
- 大きさは 1.25倍の段階と、手取りだけの大きさ

## 形と動き

- 角はほぼ直角（2px）。影は使わない。明細の紙は墨の 1px の枠で机と分ける
- 金額は条件を変えたらすぐ新しい値にする（数え上がる動きはしない）
- 動くのは、図の帯の形とスイッチだけ。`prefers-reduced-motion` では止める

## 作り物っぽさを避ける決まり（2026-11-25）

テンプレートや AI が作ったように見える定番の飾りを使わない。給与明細という実物に寄せ、数字と罫線で伝える。

| 使わないもの | 代わりにどうするか |
| --- | --- |
| 手取り率を傾けた丸い判子に見立てる飾り | 手取りの下に「手取り率 79.9%」と 1行で書く |
| 金額が数え上がる動き | すぐに新しい値を出す |
| ぼかした影（浮いて見える紙・吹き出し） | 1px の枠線で分ける |
| 字間を大きく空けた見出し（「給 与 明 細」「Z E I K I N」） | ふつうの字間 |
| カードの上の色の太い線、色を敷いた強調の箱 | 罫線だけで区切る。色は手取り・税金・社会保険・会社の負担の意味にだけ使う |
| グラデーション、すりガラス、絵文字、「〜しましょう」「！」 | 使わない |

機械で見分けられるものは `src/design-lint.test.ts` が `npm test` で止める。画面を変えるときは、この表と照らし合わせる。

## 月給を変えると（図）

- 月給 10〜120万円（いまの月給がはみ出すときは広げる）での、賞与のない月の内訳を積み上げて描く。色と順番は明細の内訳と同じ（下から手取り・税金・社会保険）
- なぞると各月給の内訳、押すとその月給に切り替わる。キーボードでは左のスライダーが同じ役目をする
- 厚生年金の保険料が増えなくなる月給（標準報酬月額 65万円）に点線を引く
- 図の上に「1万円上がると手取りはいくら増えるか」を書く。その 1万円で標準報酬月額の等級が上がるときは、そのことも書く

## 共有と印刷

- 入れた条件は URL に残す（`s`＝月給、`b`＝賞与、`pref`＝都道府県、`si=0`＝社会保険なし、`care=1`＝介護保険あり）。履歴は増やさない
- 印刷では明細と会社の負担だけを A4 に出し、上に計算の条件を 1行入れる

## 画面の幅

- 960px 以上：左に条件（画面に固定）、右に明細。1280px 以上では会社の負担と計算の前提を 2列にする
- 960px 未満：条件の下に明細。画面の下に手取りを常に出す
- 押せる部品は高さ 40〜44px 以上。キーボードの焦点は 3px の藍の枠
